# GeoAI Learnings
### Learning Objectives
1. Download RS data
2. Training and evaluating DL models using open-source tools.
---
### We learn
- Setup environment
  - Python
  - PyTorch
  - GPU Acceleration
- Download Satellite imagery from MS Planetary computer and open data portals
- Create interactive maps and prepare training datasets from large satellite data
- Train and evaluate models for seven core geospatial AI tasks:
  - Image Segmentation
  - Object detection
  - Semantic segmentation
  - Instance segmentation
  - Image translation
  - Change detection
  - Pixel level regression
- Apply foundation models
  - Segment Anything Model (SAM)
  - Vision Language models
  - Satellite embeddings
  - Real-Worls Earth Observation problems
- Run AI workflows in QGIS without writing code using Plugins fro
  - Tree segmentation,
  - Water Detection,
  - more....
